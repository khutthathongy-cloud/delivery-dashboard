# 🎁 Coupon Receipt Verification System

ระบบลงทะเบียนรับคูปองจากใบเสร็จอัตโนมัติ

## Features

- ลงทะเบียนลูกค้า
- บันทึกชื่อและเบอร์โทร
- อัปโหลดรูปใบเสร็จ
- OCR อ่านข้อมูลจากใบเสร็จ
- ตรวจสอบยอดซื้อขั้นต่ำ 300 บาท
- ตรวจสอบใบเสร็จซ้ำ
- ออกเลขคูปองอัตโนมัติ

## Technology

- HTML
- JavaScript
- Firebase
- Firestore
- Firebase Storage
- Tesseract OCR

## Installation

```bash
git clone https://github.com/khutthathongy-cloud/delivery-dashboard.git

cd delivery-dashboard
```

## Start

เปิดไฟล์

```text
index.html
```

หรือ Deploy ผ่าน GitHub Pages
